## 🌐 **Persistence Plugins Architecture (Storage, IndexedDB, Sync)**

### 1. **Mục tiêu của hệ thống Persistence**

Persistence layer của **MFEStack Query Core** cung cấp khả năng **lưu trữ trạng thái cache, queries, và mutations** giữa các phiên (sessions), tabs hoặc tiến trình khác nhau.
Mục tiêu là:

* Giảm network request lặp lại bằng cách tái sử dụng cache từ phiên trước.
* Cho phép **offline-first experience** (người dùng vẫn xem dữ liệu khi offline).
* Đồng bộ hoá cache giữa **nhiều ứng dụng hoặc tab khác nhau** trong cùng workspace.

### 3. **Thành phần chính**

#### 🧱 **Persistor Interface**

* Interface chuẩn hoá cách các lớp lưu trữ tương tác với `QueryClient`.
* Các persistor có thể hoạt động **độc lập** hoặc **chạy song song** trong pipeline.

```ts
interface Persistor {
  persistClient: (client: QueryClient) => Promise<void>;
  restoreClient: () => Promise<PersistedClient | undefined>;
  removeClient: () => Promise<void>;
}
```

---

#### 💾 **Storage Layer**

Cung cấp các driver để lưu cache ra bộ nhớ bền vững:

* **`LocalStoragePersistor`**: lưu cache nhỏ, sync nhanh, phù hợp SSR hydration.
* **`IndexedDBPersistor`**: dành cho dữ liệu lớn, lazy-loading và incremental restore.
* **`MemoryPersistor`**: fallback an toàn trong môi trường không có storage (SSR, Web Worker).
* **`CustomPersistor`**: mở rộng cho Redis, SQLite, hay KV store.

---

#### 🔄 **Sync Layer**

Giúp đồng bộ dữ liệu cache giữa nhiều instance:

* **`tabSync.ts`**: sử dụng `BroadcastChannel` API để sync cache giữa các tab.
* **`broadcastSync.ts`**: gửi thông tin invalidate, refetch qua `postMessage` hoặc WebSocket.
* **`serviceWorkerSync.ts`**: cho phép background sync khi offline/online transition.

Mỗi lớp sync có thể đăng ký vào `PersistManager`, đảm bảo không gây race condition khi nhiều sự kiện cùng lúc.

---

#### 🧩 **Persist Manager**

Là “orchestrator” chịu trách nhiệm:

* Theo dõi thay đổi trong `QueryCache` & `MutationCache`
* Gọi `persistClient()` khi có thay đổi đáng kể (throttled)
* Phục hồi cache khi khởi tạo (`restoreClient()`)

```ts
class PersistManager {
  constructor(private client: QueryClient, private persistor: Persistor) {}

  start() {
    this.restore();
    this.subscribe();
  }

  async restore() {
    const data = await this.persistor.restoreClient();
    if (data) hydrate(this.client, data);
  }

  subscribe() {
    this.client.getQueryCache().subscribe(this.persist);
  }

  persist = throttle(() => this.persistor.persistClient(this.client), 1000);
}
```

---

### 4. **Quy trình hoạt động (Lifecycle)**

1. **Restore phase**

   * Khi khởi động, `PersistManager` sẽ đọc dữ liệu từ storage.
   * Dữ liệu được **deserialize** và gửi vào `hydrate()`.

2. **Active phase**

   * Khi query/mutation thay đổi → `PersistManager` ghi lại snapshot mới (debounced).
   * Nếu có plugin sync (BroadcastChannel, SW), sẽ emit signal cho các tab khác.

3. **Sync phase**

   * Khi có sự kiện từ tab khác → gọi `invalidate()` hoặc `hydrate()` lại.
   * Giữ consistency bằng cách so sánh `timestamp` hoặc `version`.

### 5. **Tính năng nâng cao**

| Tính năng                | Mô tả                                                        |
| ------------------------ | ------------------------------------------------------------ |
| 🔐 **Encryption hooks**  | Cho phép mã hoá dữ liệu trước khi persist.                   |
| ⏱ **Throttled write**    | Giảm I/O bằng cách batch nhiều thay đổi.                     |
| 💥 **Partial hydration** | Chỉ khôi phục một phần cache (dựa trên scope hoặc queryKey). |
| 📦 **Versioned storage** | Mỗi persist có `schemaVersion` giúp migration an toàn.       |
| 🧭 **Cross-app sync**    | Hỗ trợ multi-tenant workspace bằng custom broadcast adapter. |

---

### 6. **Tích hợp với Core**

Persistence layer hoạt động như một plugin đăng ký với `QueryClient`:

```ts
import { persistQueryClient } from '@mfestack/core/plugins/persist';

persistQueryClient({
  queryClient,
  persistor: new IndexedDBPersistor(),
  dehydrateOptions: { shouldDehydrateMutation: true },
});
```

### 🔚 **Tóm tắt**

Persistence Plugin Layer trong MFEStack Query Core là một **nền tảng mở rộng, modular và resilient**, được thiết kế để hoạt động trong **đa môi trường** (browser, SSR, native) và hỗ trợ **đa ứng dụng cùng workspace**.
Nó đóng vai trò quan trọng trong việc duy trì tính **ổn định, hiệu năng và liền mạch** của dữ liệu cache trên toàn hệ sinh thái MFEStack.
