## 📡 **Event System & Cross-Layer Communication**

### **1. Overview**

Hệ thống **Event System** trong MFEStack Query Core là trục giao tiếp trung tâm giúp **kết nối giữa các layer** (Core, Plugin, Adapter, và Devtools).
Mục tiêu của nó là cung cấp một cơ chế **pub/sub bất đồng bộ**, **type-safe**, và **framework-agnostic** để truyền thông tin giữa các module mà **không tạo ra coupling trực tiếp**.

Tương tự như cơ chế “event bus” trong TanStack Query, nhưng MFEStack được thiết kế theo hướng **multi-channel** và **multi-context** nhằm hỗ trợ nhiều ứng dụng (multi-app sync) và plugin mở rộng.

---

### **2. Design Principles**

| Principle                   | Description                                                                                   |
| --------------------------- | --------------------------------------------------------------------------------------------- |
| **Decoupled Communication** | Không có dependency chéo giữa core modules.                                                   |
| **Scoped Channels**         | Mỗi instance `AppStackClient` có event bus riêng.                                             |
| **Async-safe Dispatching**  | Đảm bảo event không chặn luồng chính, hoạt động ổn định ngay cả khi nhiều event đến cùng lúc. |
| **Extensible Topics**       | Cho phép plugin, adapter, và persistence layer đăng ký chủ đề (topic) riêng.                  |

### **3. Core Components**

#### **3.1 EventEmitter**

Thành phần trung tâm, tương tự `Emitter` trong TanStack Query.
Nó quản lý danh sách listener cho từng loại sự kiện, và hỗ trợ dispatch bất đồng bộ.

```ts
class EventEmitter {
  private listeners = new Map();

  on(event, listener) {
    const set = this.listeners.get(event) || new Set();
    set.add(listener);
    this.listeners.set(event, set);
    return () => set.delete(listener);
  }

  emit(event, payload) {
    const set = this.listeners.get(event);
    if (set) {
      for (const listener of set) {
        queueMicrotask(() => listener(payload));
      }
    }
  }
}
```

---

#### **3.2 Event Topics**

Các chủ đề chính mà hệ thống Event hỗ trợ mặc định:

| Event Type           | Description                                       |
| -------------------- | ------------------------------------------------- |
| `query:added`        | Khi một `Query` mới được thêm vào `QueryCache`.   |
| `query:updated`      | Khi dữ liệu hoặc trạng thái của `Query` thay đổi. |
| `query:removed`      | Khi một `Query` bị xóa khỏi cache.                |
| `mutation:started`   | Khi một `Mutation` bắt đầu chạy.                  |
| `mutation:success`   | Khi mutation hoàn tất thành công.                 |
| `mutation:error`     | Khi mutation gặp lỗi.                             |
| `cache:invalidated`  | Khi cache được xóa hoặc invalidate.               |
| `persist:hydrated`   | Khi dữ liệu được phục hồi từ storage.             |
| `broadcast:received` | Khi nhận tín hiệu sync từ app khác.               |
| `devtools:inspect`   | Khi Devtools yêu cầu snapshot state.              |

---

#### **3.3 Scoped Event Channels**

Mỗi `AppStackClient` có `EventBus` riêng biệt, cho phép hoạt động độc lập giữa các ứng dụng hoặc context khác nhau.

```ts
const clientA = new AppStackClient({ scope: 'AppA' });
const clientB = new AppStackClient({ scope: 'AppB' });

// Không gây ảnh hưởng chéo:
clientA.events.emit('query:added', { queryKey: ['user'] });
```

### **4. Event Flow Across Layers**

Dưới đây là cách **event** di chuyển giữa các tầng:

```
[ QueryCache ] ----emit----> [ EventBus ] ----> [ Plugin Layer ]
          │                         │                   │
          │                         │                   ├── Devtools Plugin
          │                         │                   ├── Logger Plugin
          │                         │                   └── Metrics Collector
          │
          └── Observer Layer <----subscribe---- Adapter (React/Vue)
```

**Ví dụ luồng sự kiện `query:updated`:**

1. `Query` cập nhật state (data mới).
2. `QueryCache` phát `query:updated`.
3. `EventBus` dispatch tới tất cả subscriber.
4. `Observer` layer nhận thông báo và gọi `notify()`.
5. UI adapter (React hook, Vue ref...) được kích hoạt re-render.

### **5. Advanced Features**

#### **5.1 Typed Event Contracts**

MFEStack hỗ trợ định nghĩa type-safe cho event payload:

```ts
interface AppStackEvents {
  'query:updated': { queryKey: QueryKey; state: QueryState };
  'mutation:success': { mutationKey: string; data: unknown };
}

class TypedEventEmitter<T extends Record<string, any>> {
  on<K extends keyof T>(event: K, listener: (payload: T[K]) => void): void;
}
```

Điều này giúp các plugin hoặc adapter có thể **tự động gợi ý kiểu dữ liệu** trong quá trình phát triển (TypeScript IntelliSense).

---

#### **5.2 Event Replay Buffer**

Hỗ trợ **replay event** cho các listener đăng ký trễ — ví dụ, khi Devtools mở sau khi app đã chạy.

```ts
emitter.enableReplay('query:updated', 50); // lưu tối đa 50 event gần nhất
```

---

#### **5.3 Event Priorities & Queuing**

Các event có thể gán độ ưu tiên:

* `high` → dispatch ngay lập tức (critical)
* `normal` → queueMicrotask
* `low` → scheduleIdleCallback

Điều này giúp tối ưu hóa hiệu năng khi lượng event lớn.

---

### **6. Cross-Layer Communication**

Hệ thống event cũng là cơ chế chính cho **liên kết giữa các layer**:

| From                   | To                                                    | Example |
| ---------------------- | ----------------------------------------------------- | ------- |
| **Core → Plugin**      | Khi query mutate, gửi event cho logger/devtools.      |         |
| **Plugin → Core**      | Khi plugin muốn trigger invalidate hoặc refetch.      |         |
| **Persistence → Core** | Khi storage restore xong, trigger `persist:hydrated`. |         |
| **Core → Adapter**     | Khi cache thay đổi, thông báo đến UI layer.           |         |
| **Adapter → Core**     | Khi user action gọi `refetch()` hoặc `mutate()`.      |         |

Tất cả tương tác này diễn ra thông qua **EventBus**, giúp module có thể phát triển độc lập và thay thế dễ dàng.

---

### **8. Summary**

* **EventBus** là cơ chế giao tiếp thống nhất giữa các tầng (Core ↔ Plugin ↔ Adapter ↔ Persistence).
* Hỗ trợ **typed event**, **replay buffer**, **priority queue**, và **scoped isolation**.
* Tăng khả năng mở rộng và dễ dàng tích hợp với Devtools, plugin metrics, hoặc multi-app sync.
