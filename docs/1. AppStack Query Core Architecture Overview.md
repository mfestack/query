# 🧱 Technical Whitepaper: MFEStack Query Core Architecture Overview

## 1. Giới thiệu

**MFEStack Query** là một **data-fetching & caching engine thế hệ mới**, được xây dựng dựa trên triết lý của **TanStack Query**, nhưng mở rộng mạnh mẽ để đáp ứng các nhu cầu **enterprise**, **micro-frontend (MFE)** và **multi-framework**.

MFEStack Query cung cấp một core độc lập — **@mfestack/core** — có thể được tích hợp dễ dàng vào bất kỳ runtime nào (React, Vue, Svelte, Angular, VanillaJS hoặc Node).
Trên core này, các adapter như **@mfestack/react**, **@mfestack/vue** đóng vai trò cầu nối với từng framework cụ thể.

## 2. Design Philosophy

MFEStack Query được thiết kế xoay quanh ba nguyên tắc chính:

### 2.1 **Deterministic Data Flow**

Mọi dữ liệu bất đồng bộ (fetch, mutate, refetch, retry) đều được quản lý qua một pipeline nhất quán, có thể dự đoán và theo dõi được.
→ Không còn “state race” hoặc “fetch waterfall”.

### 2.2 **Plugin-first Architecture**

Thay vì cố định logic trong core, MFEStack cho phép mở rộng qua **plugin lifecycle** (onInit, onHydrate, onPersist, onQueryChange…).
Điều này biến core thành một **runtime extensible engine**, tương tự hệ thống plugin của Vite hoặc React DevTools.

### 2.3 **Micro-frontend & Multi-runtime Ready**

MFEStack hỗ trợ chia sẻ cache và state giữa **nhiều ứng dụng con** hoặc **tab trình duyệt** — một điểm giới hạn trong TanStack.
Điều này giúp hệ thống trở thành **một shared data layer** thống nhất cho toàn bộ platform.

## 3. Core Components

MFEStack Query Core bao gồm các module chính sau:

| **Nhóm**            | **Module chính**                                                                                | **Chức năng**                                                                             |
| ------------------- | ----------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------- |
| **Client**          | `QueryClient`, `createQueryClient`, `defaultOptions`                                            | Entry point quản lý query, mutation, observer & plugin lifecycle.                         |
| **Query System**    | `Query`, `QueryCache`, `QueryManager`, `QueryObserver`, `QueryFilters`, `infiniteQueryBehavior` | Toàn bộ cơ chế caching, state transition, refetch, pagination, và observer notifications. |
| **Mutation System** | `Mutation`, `MutationCache`, `MutationObserver`, `mutationDefaults`                             | Xử lý mutation logic với retry, optimistic update, rollback, cache invalidation.          |
| **Managers**        | `FocusManager`, `OnlineManager`, `NotifyManager`, `BatchManager`, `Retryer`                     | Cung cấp khả năng quản lý global state, batching, retry, network & focus detection.       |
| **Hydration**       | `dehydrate`, `hydrate`, `hydrationUtils`                                                        | SSR hydration & dehydrate pipeline — serialize & restore cache giữa server/client.        |
| **Plugins**         | `persistPlugin`, `broadcastPlugin`, `loggerPlugin`, `devtoolsPlugin`                            | Hệ thống mở rộng với interface `Plugin.ts`.                                               |
| **Utils**           | `hash`, `stableStringify`, `replaceEqualDeep`, `scheduler`, `cancelController`                  | Tiện ích cho hashing, structural sharing, async control, task scheduling.                 |

## 4. Plugin System

### 4.1 Plugin Lifecycle

Plugin có thể hook vào lifecycle của QueryClient:

```ts
interface Plugin {
  onInit?(client: QueryClient): void
  onQueryChange?(query: Query): void
  onHydrate?(state: HydrationState): void
  onPersist?(cache: QueryCache): void
  onDestroy?(): void
}
```

### 4.2 Built-in Plugins

* 🧩 **PersistPlugin** — lưu cache vào LocalStorage, IndexedDB, hoặc Redis.
* 🌐 **BroadcastPlugin** — đồng bộ cache đa tab hoặc đa ứng dụng thông qua BroadcastChannel hoặc WebSocket.
* 🧰 **DevToolsPlugin** — hiển thị dữ liệu realtime trong DevTools UI.
* 🪶 **LoggerPlugin** — log lifecycle của query và mutation.

## 5. Cache Model

MFEStack Query sử dụng mô hình **Normalized Cache Tree**, trong đó mỗi `Query` được định danh bởi `QueryKey` (được hash bằng `hash.ts`).
Cache được lưu trữ tại `QueryCache`, có thể:

* Refetch theo `staleTime`
* Invalidate theo `QueryKey` hoặc `Predicate`
* Sync với cache khác (qua broadcast/persist)

Cơ chế **structural sharing** giúp tránh re-render khi dữ liệu không thay đổi (`replaceEqualDeep`).

---

## 6. Hydration & SSR

MFEStack hỗ trợ SSR theo pipeline hai chiều:

```ts
// Server
const dehydrated = dehydrate(queryClient)
return renderToString(<App />, dehydrated)

// Client
const state = window.__APPSTACK_STATE__
hydrate(queryClient, state)
```

Hydration có thể selective theo query filter, tránh restore dữ liệu cũ hoặc lỗi thời.

---

## 7. Multi-App Synchronization

Thông qua **BroadcastPlugin**, MFEStack cho phép:

* Chia sẻ cache giữa các tab trình duyệt
* Đồng bộ cache giữa nhiều micro-app (SPA, iframe, hoặc module federation)
* Giao tiếp realtime qua BroadcastChannel / WebSocket adapter

Điều này tạo ra một **Global Query Mesh Layer** – nơi các ứng dụng nhỏ vẫn dùng chung một nguồn dữ liệu.

---

## 8. Architecture Target

| **Layer**                                        | **Purpose**                                                     |
| ------------------------------------------------ | --------------------------------------------------------------- |
| **Core (@mfestack/core)**                        | Framework-agnostic runtime, cache, managers, plugins            |
| **Adapters (@mfestack/react, @mfestack/vue, …)** | Cung cấp hook như `useQuery`, `useMutation`, `useInfiniteQuery` |
| **DevTools (@mfestack/devtools)**                | Giao diện quan sát state & cache                                |
| **Persistence (@mfestack/persist-client)**       | Optional module cho IndexedDB/Storage driver                    |
| **Shared Layer**                                 | Dành cho multi-app cache sharing hoặc data federation           |

## 10. Kết luận

> MFEStack Query đại diện cho thế hệ kế tiếp của TanStack Query –
> Một **Unified Async Data Engine** có thể hoạt động trong mọi môi trường, chia sẻ state giữa nhiều ứng dụng,
> mở rộng qua plugin system, và sẵn sàng cho các kiến trúc **Enterprise-scale / Micro Frontend / Cross-runtime**.
