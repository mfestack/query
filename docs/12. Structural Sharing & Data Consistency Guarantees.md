## 🧩 **Structural Sharing & Data Consistency Guarantees**

### **1. Overview**

**Structural Sharing** là cơ chế nền tảng của **MFEStack Query Core**, đảm bảo:

* Dữ liệu trong cache được **cập nhật chính xác** mà không tạo object mới không cần thiết.
* Giảm số lần render lại trong UI layer (React/Vue/Angular).
* Duy trì **consistency** giữa các cache instance, ngay cả trong môi trường nhiều client (multi-scope).

Khái niệm này kế thừa từ TanStack Query (`replaceEqualDeep`), nhưng MFEStack mở rộng hơn:

* Có **multi-layer consistency model** (cache, observers, persistence).
* Hỗ trợ **partial structural update** cho large payloads.
* Tích hợp trực tiếp với **scheduler & event system** để tránh race condition.

---

### **2. Core Principle**

Structural sharing nghĩa là:

> Nếu dữ liệu mới “deep equal” với dữ liệu cũ, MFEStack sẽ tái sử dụng object reference cũ thay vì tạo object mới.

Điều này giúp:

* Tránh unnecessary GC (garbage collection).
* Giảm shallow-compare diff trong frameworks.
* Cải thiện hiệu năng refetch & cache hydration.

---

### **3. Implementation Flow**

MFEStack triển khai **Structural Sharing Engine** tại module `utils/replaceEqualDeep.ts`.

```ts
export function replaceEqualDeep<T>(a: T, b: T): T {
  if (a === b) return a
  if (typeof a !== 'object' || typeof b !== 'object' || !a || !b) return b

  const aKeys = Object.keys(a)
  const bKeys = Object.keys(b)
  const newObj: Record<string, any> = {}
  let same = true

  for (const key of bKeys) {
    newObj[key] = replaceEqualDeep((a as any)[key], (b as any)[key])
    if (newObj[key] !== (a as any)[key]) same = false
  }

  return same && aKeys.length === bKeys.length ? a : (newObj as T)
}
```

Cơ chế này:

1. So sánh từng cấp sâu trong object.
2. Giữ nguyên reference nếu giá trị không đổi.
3. Chỉ tạo object mới ở nhánh dữ liệu thay đổi.

---

### **4. Data Consistency Model**

MFEStack chia consistency thành **3 cấp độ**:

| Level                          | Scope                                  | Guarantee                                             | Mechanism                                |
| ------------------------------ | -------------------------------------- | ----------------------------------------------------- | ---------------------------------------- |
| **Local Consistency**          | Trong 1 Query instance                 | Dữ liệu luôn phản ánh fetch mới nhất hoặc cache state | Query State Reducer + Structural Sharing |
| **Cross-Observer Consistency** | Giữa các component observer cùng Query | Observer luôn nhận reference giống nhau               | Shared Query Reference                   |
| **Cross-Client Consistency**   | Giữa các client trong scope khác nhau  | Dữ liệu đồng bộ theo event `cache:updated`            | Broadcast Plugin + Structural Merge      |

---

### **5. Structural Merge (Cross-Client Updates)**

Khi nhiều client (VD: React & Vue app) cùng dùng cache chung, MFEStack dùng cơ chế **“structural merge”** để hợp nhất dữ liệu mà không phá vỡ reference tree:

```ts
mergeQueryData(targetCache, sourceCache) {
  for (const query of sourceCache.getAll()) {
    const existing = targetCache.get(query.key)
    const merged = replaceEqualDeep(existing?.state?.data, query.state?.data)
    targetCache.set(query.key, { ...query, state: { ...query.state, data: merged } })
  }
}
```

Điều này đảm bảo:

* Không mất reference nếu dữ liệu giống nhau.
* Không cần refetch toàn bộ khi có update nhẹ.

---

### **6. Partial Update Propagation**

MFEStack dùng **observer diffing** để chỉ update những phần cần thiết:

```
fetch → QueryStateReducer → Structural Diff → Observer notify (minimal)
```

Observer chỉ nhận thông báo nếu object reference thay đổi sau quá trình `replaceEqualDeep`.

Kết quả:

* UI không re-render nếu dữ liệu không đổi.
* Cache sync nhanh và ổn định hơn nhiều client khác.

---

### **7. Integration with Persistence & Broadcast**

Cơ chế sharing còn liên kết với:

* **Persistence Plugin:** Khi cache được restore, `replaceEqualDeep` hợp nhất với cache hiện tại.
* **Broadcast Plugin:** Khi tab khác cập nhật cache, dữ liệu merge lại mà không overwrite toàn bộ.

Điều này giúp duy trì **strong eventual consistency** giữa nhiều scope hoặc tab.

### **9. Summary**

* MFEStack sử dụng **replaceEqualDeep** mở rộng để kiểm soát dữ liệu đa tầng.
* Cung cấp **data consistency guarantees** mạnh mẽ ở mọi cấp độ (local, cross-observer, cross-client).
* Kết hợp structural sharing với **event-driven cache sync**, giúp tối ưu hiệu năng, đảm bảo data integrity trong môi trường đa ứng dụng.
