## 🧩 **Notification & Observer Management System**

### **1. Overview**

Hệ thống **Notification & Observer Management** của MFEStack Query Core chịu trách nhiệm cho việc:

* Theo dõi sự thay đổi của `Query` và `Mutation` state.
* Đồng bộ hóa UI và logic reactive layer của framework (React, Vue, Solid, Svelte, v.v).
* Giảm thiểu việc render thừa, nhờ cơ chế diff thông minh và batching notification.

Mục tiêu của hệ thống này là cung cấp một mô hình **Observer Pattern** tinh gọn, có khả năng mở rộng, và framework-agnostic.

---

### **2. Core Components**

#### **2.1 Observer**

Là cầu nối giữa `Query`/`Mutation` và layer UI (hoặc logic layer khác).

Mỗi `Observer`:

* Theo dõi một `Query` hoặc `Mutation`.
* Lưu trữ `result` (data, error, status) của lần render gần nhất.
* Cung cấp API như `subscribe(callback)` và `unsubscribe(callback)`.

```ts
class QueryObserver {
  constructor(client, query) {
    this.client = client;
    this.query = query;
    this.listeners = new Set();
  }

  subscribe(listener) {
    this.listeners.add(listener);
    this.update();
    return () => this.listeners.delete(listener);
  }

  notify() {
    this.listeners.forEach(listener => listener(this.getResult()));
  }

  getResult() {
    return this.query.state;
  }
}
```

---

#### **2.2 QueryNotifier**

Một lớp trung gian quản lý việc batching và dispatch thông báo.

* Gom các event thay đổi từ nhiều queries/mutations trong cùng tick event loop.
* Giúp tránh tình trạng render thừa hoặc dispatch quá nhiều lần.

```ts
class QueryNotifier {
  queue = new Set();

  scheduleNotify(observer) {
    this.queue.add(observer);
    if (!this.scheduled) {
      this.scheduled = true;
      queueMicrotask(() => this.flush());
    }
  }

  flush() {
    this.queue.forEach(observer => observer.notify());
    this.queue.clear();
    this.scheduled = false;
  }
}
```

---

#### **2.3 MutationObserver**

Tương tự như `QueryObserver`, nhưng theo dõi `mutation` lifecycle:

* Khi `onMutate`, `onSuccess`, `onError`, hoặc `onSettled` được gọi.
* Có thể kết hợp với plugin system để dispatch event đến logging, devtools, v.v.

---

### **3. Notification Flow**

**Flow chi tiết:**

1. **State Change**
   Khi `QueryCache` hoặc `MutationCache` cập nhật dữ liệu, chúng gọi `query.notifyObservers()`.
2. **Batching**
   `QueryNotifier` nhận các observer cần cập nhật, gom chúng lại.
3. **Diff Calculation**
   Mỗi observer tính toán `prevResult !== newResult`. Nếu có thay đổi, trigger update.
4. **Callback Dispatch**
   Các listener (UI, plugin, hoặc adapter) được gọi để cập nhật giao diện hoặc sync state.

### **4. Optimization Techniques**

| Technique                  | Description                                                  |
| -------------------------- | ------------------------------------------------------------ |
| **Result Memoization**     | Tránh tạo object result mới nếu state không thay đổi.        |
| **Structural Sharing**     | Dữ liệu cache sử dụng shallow equality để giảm chi phí diff. |
| **Batching Notifications** | Gom nhiều notify vào cùng microtask tick.                    |
| **Lazy Subscription**      | Chỉ active observer khi có ít nhất một subscriber thật sự.   |

### **5. Observer Hierarchy**

```
QueryCache
 ├── Query (id=users)
 │     ├── QueryObserver (component A)
 │     ├── QueryObserver (component B)
 │     └── DevtoolsObserver
 ├── Query (id=posts)
 │     ├── QueryObserver (component C)
```

* `Query` quản lý state (data, error, timestamps)
* `QueryObserver` đại diện cho mỗi context UI sử dụng query đó.
* `QueryCache` là global registry chứa tất cả queries đang hoạt động.

### **6. Integration Points**

| Integration Layer     | Usage                                                              |
| --------------------- | ------------------------------------------------------------------ |
| **React Adapter**     | `useQuery()` hook subscribe/unsubscribe thông qua `QueryObserver`. |
| **Vue Adapter**       | Dùng `watchEffect` hoặc `ref` để re-render khi observer notify.    |
| **Devtools Plugin**   | Lắng nghe toàn bộ sự kiện từ `Notifier` để hiển thị logs.          |
| **Persistence Layer** | Sync lại khi cache được hydrate hoặc restore từ localStorage.      |

---

### **7. Advanced Use Cases**

* **Selective Subscription:**
  Cho phép observer chỉ theo dõi một phần của state (`select` function).

* **Custom Notifiers:**
  Cho phép tích hợp hệ thống thông báo bên ngoài như RxJS, EventEmitter, hoặc WebSocket.

* **Observer Scopes:**
  Hỗ trợ phân tách observer theo app scope hoặc context (multi-app mode).
