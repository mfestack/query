## 🧩 Plugin System & Extensibility Layer

### 1. Design Philosophy

MFEStack Query Core được thiết kế với **plugin-first architecture**, lấy cảm hứng từ hệ thống plugin của TanStack nhưng mở rộng khả năng **modular injection** và **runtime composition**.
Triết lý chính là:

> “Core stays minimal, everything else is pluggable.”

Điều này có nghĩa là các thành phần như persistence, broadcast, hoặc logging không nằm trong core mà được cài đặt như **plugin độc lập** có thể được inject vào runtime thông qua `QueryClient.registerPlugin()`.

---

### 2. Plugin Interface

Mọi plugin trong MFEStack Query tuân theo một interface chuẩn:

```ts
export interface AppStackPlugin {
  id: string;                        // unique identifier
  onInit?: (client: QueryClient) => void;
  onQueryAdded?: (query: Query) => void;
  onQueryRemoved?: (query: Query) => void;
  onMutationAdded?: (mutation: Mutation) => void;
  onMutationSuccess?: (mutation: Mutation, data: any) => void;
  onPersist?: (snapshot: PersistedSnapshot) => void;
  onRestore?: (client: QueryClient, snapshot: PersistedSnapshot) => void;
  dispose?: () => void;
}
```

👉 **Tính năng nổi bật**:

* Có thể hook vào **mọi giai đoạn lifecycle** (query/mutation/persistence).
* Hỗ trợ **runtime enable/disable** mà không cần rebuild.
* Có thể **chain nhiều plugin** theo thứ tự đăng ký (giống middleware stack).

---

### 3. Core Plugin Implementations

MFEStack cung cấp sẵn một số plugin mẫu tương đương TanStack:

| Plugin              | Mục đích                                                                           | Ghi chú                                                             |
| ------------------- | ---------------------------------------------------------------------------------- | ------------------------------------------------------------------- |
| **PersistPlugin**   | Lưu trạng thái query/mutation xuống storage (localStorage, IndexedDB, Redis, etc.) | tương tự `persistQueryClient` của TanStack nhưng tách rời khỏi core |
| **BroadcastPlugin** | Đồng bộ cache giữa nhiều tab/browser qua BroadcastChannel hoặc WebSocket           | tương tự `broadcastQueryClient`                                     |
| **LoggerPlugin**    | Hook log toàn bộ query/mutation lifecycle                                          | dùng trong devtool                                                  |
| **RetryPlugin**     | Mở rộng Retryer behavior mặc định (thêm exponential backoff, custom jitter)        | có thể override Retryer core                                        |
| **FocusPlugin**     | Cung cấp cơ chế custom trigger refetch khi app regain focus                        | inject vào FocusManager                                             |
| **NetworkPlugin**   | Theo dõi online/offline state thông qua NetworkInformation API                     | tương tự `OnlineManager`                                            |

---

### 4. Plugin Lifecycle

**Plugin Initialization Flow:**

1. Khi `QueryClient` khởi tạo, nó đọc danh sách plugin từ `options.plugins`.
2. Gọi `plugin.onInit(client)` để thiết lập environment.
3. Khi có event lifecycle (e.g., query added, mutation success), client sẽ gọi callback tương ứng trong plugin.
4. Khi `client.clear()` hoặc `client.destroy()` được gọi → tất cả plugin sẽ gọi `plugin.dispose()` để dọn tài nguyên.

**Example:**

```ts
const client = new QueryClient({
  plugins: [
    new PersistPlugin({ storage: localStorage }),
    new BroadcastPlugin({ channel: 'mfestack-sync' }),
    new LoggerPlugin(),
  ],
});
```

---

### 5. Plugin Composition

MFEStack hỗ trợ **chaining plugin events** theo cơ chế event emitter đa tầng:

* Mỗi plugin có thể **transform dữ liệu** hoặc **ngăn event lan truyền** (như middleware).
* Cho phép viết plugin dựa trên plugin khác (ví dụ: `PersistPlugin` sử dụng `LoggerPlugin` để ghi log restore event).

```ts
client.emit('mutationSuccess', mutation, data);
```

→ Hệ thống plugin sẽ duyệt tất cả plugin đăng ký và gọi `onMutationSuccess` nếu có.

### 6. Extensibility in the Ecosystem

Nhờ kiến trúc plugin, MFEStack có thể dễ dàng mở rộng ra ngoài data-fetching thuần túy:

| Use case             | Mô tả                                                      |
| -------------------- | ---------------------------------------------------------- |
| **Analytics Plugin** | Gửi metric về performance của query/mutation               |
| **Audit Plugin**     | Ghi lại lịch sử thay đổi dữ liệu vào audit log             |
| **Auth Plugin**      | Tự động refresh token khi query gặp lỗi 401                |
| **DevTool Bridge**   | Kết nối MFEStack Query với custom devtool UI qua WebSocket |

---

### 7. Comparison with TanStack

| Capability                    | TanStack Query     | MFEStack Query                   |
| ----------------------------- | ------------------ | -------------------------------- |
| Hook-based persistence        | ✅                  | ✅ (via plugin)                   |
| Broadcast multi-tab sync      | ✅                  | ✅ (pluginized, optional)         |
| Logging                       | Partial            | ✅ fully modular                  |
| Retry customization           | Limited to Retryer | ✅ via RetryPlugin                |
| Plugin chaining               | ❌                  | ✅ Middleware-like chain          |
| Runtime plugin toggle         | ❌                  | ✅ `enable/disable` supported     |
| External ecosystem plugin API | ❌                  | ✅ Public Plugin Registry planned |

---

### 8. Future Directions

* **Plugin Registry:** Cung cấp kho plugin cộng đồng (tương tự npm nhưng scoped theo `@mfestack/query-plugin-*`).
* **Devtool Integration SDK:** Cho phép plugin tạo custom event gửi về DevTool.
* **Dynamic Plugin Loading:** Hỗ trợ `import()` plugin theo môi trường runtime (browser/server).
