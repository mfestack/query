# 🧩 MFEStack Core: Adapter Integration & Framework Layer

### React · Vue · Solid · Svelte

---

## 1. 🎯 Triết lý thiết kế Adapter

MFEStack tách biệt rõ ràng giữa **business logic** (core) và **UI binding** (adapter):

| Layer                                               | Vai trò                                         | Đặc điểm                                             |
| --------------------------------------------------- | ----------------------------------------------- | ---------------------------------------------------- |
| **Core (`@mfestack/core`)**                         | Xử lý query, mutation, cache, plugin, hydration | Framework-agnostic, không dùng hook hay reactive API |
| **Adapter (`@mfestack/react`, `@mfestack/vue`, …)** | Cung cấp API native cho từng framework          | Wrap lại core bằng hook hoặc reactive store          |

Mục tiêu:

* Mỗi adapter là **một lớp mỏng** bao quanh core.
* Toàn bộ logic caching, retry, hydration, notify… nằm trong core.
* Adapter chỉ chịu trách nhiệm **subscribe vào `QueryObserver`** và phản ánh state đó ra UI framework.

## 3. 🧠 Luồng hoạt động giữa Adapter và Core

### Khi gọi `useQuery()` trong React:

```tsx
const { data, error, isLoading } = useQuery({
  queryKey: ['todos'],
  queryFn: fetchTodos,
});
```

#### Diễn ra ngầm:

1. **Adapter layer** gọi `queryClient.getQueryCache().build()` để tạo hoặc lấy `Query` instance.
2. Tạo `QueryObserver` (từ core) và subscribe vào query.
3. Khi state thay đổi, `NotifyManager` kích hoạt observer callback.
4. Hook React cập nhật state (`setState`) → re-render component.
5. Khi component unmount → observer tự động unsubscribe.

#### Sequence Diagram

```
React Hook → QueryClient → QueryCache → Query → QueryObserver
     ↑                                     │
     └──────────── NotifyManager <─────────┘
```

## 4. 🧩 Vue Adapter (`@mfestack/vue`)

Vue sử dụng **reactivity system** thay vì hook.
Adapter chuyển observer updates thành `ref` hoặc `computed` reactive state.

```ts
import { useQuery } from '@mfestack/vue'

const { data, isLoading } = useQuery({
  queryKey: ['user', id],
  queryFn: fetchUser,
})
```

### Nội bộ hoạt động:

* `useQuery` tạo `QueryObserver`
* Dùng `shallowRef` lưu trữ state
* Khi observer phát notify → reactive state cập nhật
* Vue tự động phản ứng và re-render template

## 5. 🧱 Solid & Svelte Adapter

Cả hai adapter hoạt động tương tự Vue, sử dụng reactive primitives thay vì stateful hook:

| Framework  | API             | Binding Mechanism                   |
| ---------- | --------------- | ----------------------------------- |
| **Solid**  | `createQuery()` | `createSignal()` + `createEffect()` |
| **Svelte** | `useQuery()`    | `writable()` store + `$subscribe`   |
| **React**  | `useQuery()`    | React Context + useState/useEffect  |
| **Vue**    | `useQuery()`    | Vue Ref + watchEffect               |

## 6. 🔌 QueryClientProvider Across Frameworks

Mỗi adapter đều cung cấp một `Provider` tương ứng —
đây là cầu nối giữa ứng dụng và `QueryClient` từ core.

| Framework | Provider                                     | Mô tả              |
| --------- | -------------------------------------------- | ------------------ |
| React     | `<QueryClientProvider client={queryClient}>` | Dùng Context       |
| Vue       | `app.provide('QueryClient', queryClient)`    | Vue provide/inject |
| Solid     | `<QueryClientProvider value={queryClient}>`  | Context API        |
| Svelte    | `setContext('queryClient', queryClient)`     | Svelte context     |

Điều này đảm bảo **core không phụ thuộc framework nào**, chỉ yêu cầu truyền `queryClient` vào root app.

## 8. 🔍 Adapter Lifecycle Integration

Tất cả adapter đều gắn liền với **MFEStack Core lifecycle events**:

| Event            | Callback               | Adapter Reaction               |
| ---------------- | ---------------------- | ------------------------------ |
| `onQueryAdded`   | khi query mới được tạo | Subscribe UI vào QueryObserver |
| `onQueryUpdated` | state thay đổi         | Trigger render/update          |
| `onQueryRemoved` | cleanup                | Unsubscribe observer           |
| `onFocus`        | tab focus              | Adapter trigger `refetch`      |
| `onOnline`       | mạng có lại            | Resume paused fetch            |
| `onHydrate`      | SSR restore            | Đồng bộ UI state ban đầu       |

## 9. 💡 Multi-Framework Consistency Layer

MFEStack còn cung cấp **“Bridge Interface”** (`AppStackBridge`) để đảm bảo consistency:

```ts
interface AppStackBridge {
  createQueryObserver(): QueryObserver
  createMutationObserver(): MutationObserver
  createReactiveBinding<T>(initial: T): Reactive<T>
  notifyChange(): void
}
```

Mỗi adapter chỉ cần implement 3–4 hàm interface này để tương thích với core —
giúp việc thêm framework mới (ví dụ Angular, Qwik, Preact) cực kỳ dễ dàng.

---

## 10. ✅ Summary

MFEStack Adapter Layer mang lại:

* **Cross-framework consistency** nhờ một core thống nhất.
* **Framework-native experience** qua API hook/store/ref quen thuộc.
* **Hydration-safe** khi dùng SSR hoặc multi-tab persistence.
* **Pluggable UI layer**, dễ mở rộng cho framework mới.
